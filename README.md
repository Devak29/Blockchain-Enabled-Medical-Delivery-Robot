# Blockchain Enabled Secure Medical Delivery Robot Using IoT

## Overview
This project presents an IoT-enabled autonomous medical delivery robot designed for smart hospitals. The robot securely delivers medicines using RFID authentication and verifies medicine retrieval using an IR sensor. A blockchain-inspired SHA-256 hashing mechanism ensures data integrity, while ThingSpeak provides real-time monitoring through a web dashboard.

## Features
- ESP8266 NodeMCU-based robot
- RFID authentication for secure medicine access
- IR sensor for medicine retrieval detection
- Servo motor-controlled medicine compartment
- ThingSpeak cloud integration
- Web dashboard for real-time monitoring
- SHA-256 hashing for secure delivery records
