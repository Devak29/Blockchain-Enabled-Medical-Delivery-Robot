## 📖 Project Overview

This project presents an **IoT-enabled autonomous medical delivery robot** designed for **smart healthcare environments**. The robot securely delivers medicines using **RFID-based authentication**, verifies successful retrieval through an **IR sensor**, and records delivery information using a **SHA-256 blockchain-inspired hashing mechanism** to ensure data integrity.

A **ThingSpeak cloud dashboard** provides real-time monitoring of delivery status, enabling secure, reliable, and intelligent medicine distribution.

---

## ✨ Key Features

- 🔐 RFID-based secure medicine authentication
- 🤖 Autonomous medicine delivery robot
- 📦 Servo-controlled medicine compartment
- 📡 Real-time IoT monitoring using ThingSpeak
- 📍 IR sensor for medicine retrieval confirmation
- 🔒 SHA-256 hashing for secure delivery records
- 🌐 Live web dashboard for remote monitoring
